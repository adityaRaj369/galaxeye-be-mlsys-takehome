How we train

The assignment did not name a model. They gave labelled folders and said train or use a pretrained local model. We trained on their data only.

Where the labels came from

Not from eval_labels.csv. That file is a hidden test set.

Training labels are the folder names in the zip they sent:

data/be-mlsys-assignment-dataset/candidate_tiles/Forest/ … 150 PNGs per class, 7 classes, 1050 tiles.

What we do in scripts/train.py

  1. Open every PNG under each class folder.
  2. Turn the image into numbers: 16-bin RGB histograms, an 8×8 colour thumbnail, and per-channel mean/std. Same function used at predict time (app/features.py).
  3. Hold out 20% of those tiles to sanity-check.
  4. Fit a scikit-learn RandomForest on the rest, then refit on all 1050.
  5. Score eval_set/ against eval_labels.csv. Current number: {% if eval_acc %}{{ (eval_acc * 100)|round(1) }}%{% else %}run train.py{% endif %}. Highway is the weak class. They are not grading this.
  6. Write artifacts/landuse_clf.joblib — the model file the API loads.
python scripts/train.py

What we did not do

No OpenAI, no cloud vision, no extra satellite download, no new fake tiles. After training, inference does not need the internet or the CSV.

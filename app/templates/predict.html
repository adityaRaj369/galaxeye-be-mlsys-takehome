How we predict

This is the required Part 2 path. The model never receives the filename or eval_labels.csv.

Route

POST /tiles (JSON API) or the form on /ingest which POSTs to /ingest and redirects to the stored tile.

Steps on every upload

  1. Read the file as raw bytes.
  2. Open it as an RGB image. If it is not an image, return 400.
  3. Build the same feature vector as training (features_from_bytes).
  4. Call RandomForest.predict_proba on landuse_clf.joblib.
  5. Take the top class and its probability.
  6. If confidence is below {{ threshold }}, mark needs_review. We still store the row. We do not drop the tile.
  7. Save: predicted label, full scores, model version, sha256 of the bytes, and a copy of the PNG.

How you know it is not a filename lookup

  • Upload Forest tile_001.png renamed to anything — still Forest.
  • tile_002.png is Forest in the CSV; the model often says SeaLake.
  • predict_bytes(data) has no filename argument. See app/classifier.py.
